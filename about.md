# Very Simple Systems

# ROTATE BUTTON

Adds a rotation button to the pause menu, making a 3d like effect. yes it doesn't actually rotate the full thing - has a limit of 175

# POSITION BUTTON

Adds a position button to the pause menu that changes the position of the game

# VERY SIMPLE QUESTS

Adds a random quest button to the creator menu

You don't really get anything for completing the quest... however it's a fun way to keep playing GD.

It's like normal quests, but way more specific and less exciting-

# DIALOG

Besides that there is also special dialog included, meaning there is special buttons to see more dialog from characters (mostly just in the creator tab).

# VERY SIMPLE FEATURED LEVEL SYSTEM THING 

Also Includes a featured level button, which I update every so often
I'm not promoting my levels just other levels people have made
